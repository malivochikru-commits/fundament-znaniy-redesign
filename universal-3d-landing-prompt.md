## СТЕК И ФОРМАТ ВЫВОДА

По умолчанию: **один самодостаточный HTML-файл**, без сборки —
Three.js подключается через CDN (unpkg/cdnjs), GSAP (+ ScrollTrigger) для анимаций.

Если пользователь работает в React-окружении — используй **React Three Fiber**
(`@react-three/fiber`, `@react-three/drei`) вместо чистого Three.js, сохраняя
всю остальную структуру промпта без изменений.

Технические требования:
- WebGL-рендер должен деградировать без ошибок на устройствах без GPU-ускорения
  (fallback: статичный градиент/постер вместо канваса).
- Целевая частота кадров — 60 fps на десктопе, не ниже 30 fps на мобильных.
- Вес сцены (геометрия + текстуры) — держать минимальным: без внешних .glb-файлов,
  если явно не сказано, что модель будет предоставлена.

## КЛЮЧЕВАЯ ЗАДАЧА: 3D БЕЗ ГОТОВОЙ 3D-МОДЕЛИ

У тебя не будет файла реальной 3D-модели продукта. Собери **процедурную
стилизованную репрезентацию** из примитивов Three.js (Box, Cylinder, Torus,
Sphere, Capsule, ExtrudeGeometry, RoundedBox), скомпонованных так, чтобы форма
угадывалась и выглядела презентабельно, а не буквально.

Логика подбора примитивов под тип продукта (расширяй по аналогии для любых
других категорий):

| Продукт | Базовая композиция |
|---|---|
| Наушники (накладные) | Torus/дуга оголовья + два сплюснутых Sphere/Capsule как чашки |
| Наушники (вставные, TWS) | Кейс — RoundedBox с крышкой на шарнире; сами наушники — Capsule + маленький Cylinder-«ножка» |
| Клавиатура | Плоский RoundedBox-корпус + сетка мелких BoxGeometry-клавиш с индивидуальным чуть разным отступом/высотой |
| Банковская/подарочная карта | Тонкий RoundedBox с закруглением, металлик/голографик материал, слегка выступающий чип-прямоугольник |
| Смартфон/телефон | RoundedBox-корпус + тонкий Plane-«экран» с эмиссивным материалом поверх |
| Часы | Cylinder-корпус + Torus-ремешок, Circle-циферблат |
| Бутылка/парфюм | LatheGeometry для профиля бутылки + Cylinder-крышка |
| Кроссовок/обувь | ExtrudeGeometry по кастомному 2D-контуру подошвы + Capsule-объёмы для верха |

Если продукт не из таблицы — по аналогии реши, какая комбинация 3–6 примитивов
лучше всего читается как силуэт этого объекта. Не переусложняй: 3D-лендинг
работает за счёт света, материалов и движения, а не полигональной детализации.

## МАТЕРИАЛЫ И СВЕТ

- Материал по умолчанию: `MeshPhysicalMaterial` с `metalness`, `roughness`,
  `clearcoat` — под премиальный «студийный» вид (матовый пластик / шлифованный
  металл / стекло — выбери исходя из типа продукта).
- Окружение: `RoomEnvironment` или синтетический HDRI-градиент через
  `PMREMGenerator`, без загрузки внешних .hdr-файлов.
- Свет: 1 key light (направленный, тёплый), 1 fill light (мягкий, холодный),
  1 rim/back light для контура — классическая продуктовая 3-точечная схема.
- Тени: мягкие contact shadows под объектом (`ContactShadows` из drei или
  `ShadowMaterial` на плоскости), без резких жёстких теней.
- Фон сцены — не белый по умолчанию: используй тонкий градиент или студийный
  циклорама-эффект (плавный переход стена→пол).

## СТРУКТУРА СТРАНИЦЫ

1. **Hero** — 3D-модель продукта в центре, крупный заголовок, короткий
   подзаголовок, один CTA. Модель мягко покачивается / медленно вращается
   в состоянии покоя (idle-анимация), реагирует на движение курсора
   (parallax-наклон по X/Y на небольшой угол).
2. **Scroll-driven секция** — при скролле 3D-объект меняет ракурс/масштаб/
   позицию синхронно со сменяющимися текстовыми блоками-фичами (через
   GSAP ScrollTrigger, привязка к таймлайну камеры).
3. **Детали/особенности** — 3–4 карточки с ключевыми характеристиками
   продукта (текст под конкретный продукт, не универсальные заглушки).
4. **Варианты/цвета** — если применимо к продукту, переключатель, который
   меняет материал/цвет 3D-модели в реальном времени по клику.
5. **Технические характеристики** — компактная таблица или сетка.
6. **Финальный CTA** — повтор продукта (можно уменьшенная версия сцены)
   + кнопка действия.

Не добавляй разделы, не относящиеся к типу продукта (например, «варианты
цвета» для товара, который продаётся в одном исполнении).

## АНИМАЦИЯ И ВЗАИМОДЕЙСТВИЕ

- Idle-анимация: медленное вращение/покачивание, амплитуда небольшая —
  не должно выглядеть как «крутящаяся сувенирка».
- Скролл: используй GSAP ScrollTrigger для связки прогресса скролла
  с камерой/ротацией/позицией модели — не завязывай ключевую анимацию
  на `requestAnimationFrame` без привязки к скроллу.
- Курсор/тач: лёгкий параллакс-наклон модели вслед за указателем
  (ограничить угол, чтобы не укачивало).
- Появление текстовых блоков — fade/slide с небольшой задержкой,
  синхронизировано с движением 3D-объекта, а не отдельно от него.
- Никаких автозапускающихся звуков.

## ДИЗАЙН-ЯЗЫК

- Минимализм, много воздуха, крупная типографика для заголовков.
- Тёмная или светлая монохромная база + один акцентный цвет,
  подобранный под характер продукта (не «дефолтный синий»).
- Шрифты — системные без засечек или одна выразительная пара
  (заголовочный + текстовый), без более чем 2 гарнитур.
- Никаких дефолтных теней Bootstrap/Material — только кастомные,
  мягкие, соответствующие свету 3D-сцены.

## АДАПТИВНОСТЬ И ПРОИЗВОДИТЕЛЬНОСТЬ

- Полная адаптация под мобильные: на маленьких экранах допустимо снижать
  сложность сцены (меньше объектов света, ниже pixel ratio через
  `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`).
- Ленивая инициализация Three.js-сцены (только когда hero-блок в viewport).
- `prefers-reduced-motion`: при активном флаге — отключать idle-анимацию
  и параллакс, оставлять только статичную модель.

## ЧТО ПОДСТАВЛЯТЬ ПОД КОНКРЕТНЫЙ ЗАПРОС

Когда пользователь называет продукт, определи и заполни сам, без вопросов
(если это очевидно из типа продукта):

- `{PRODUCT_NAME}` — название
- `{PRODUCT_TYPE}` — категория → используется для выбора примитивов из таблицы
- `{MATERIAL_STYLE}` — металл / матовый пластик / стекло / ткань / кожа
- `{ACCENT_COLOR}` — акцентный цвет, уместный для категории
- `{KEY_FEATURES}` — 3–4 реалистичные характеристики этого типа продукта
- `{HAS_COLOR_VARIANTS}` — да/нет — включать ли переключатель цветов

Если каких-то данных о продукте объективно не хватает для честного текста
(точные технические характеристики, цена, дата выхода) — не выдумывай их:
оставляй плейсхолдер вида `[уточнить: цена]`, а не придуманное число.
